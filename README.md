# HMS_HR_SYSTEM
Human Resource Application
# HMS Landing Website

A responsive frontend website designed for an HR Management System platform. The project was developed to showcase HR services, company information, and provide access to the HR management system dashboard.

## Features

* Responsive Homepage Design
* Navigation Bar
* Services Section
* About Section
* Contact Section
* Modern UI Layout
* Mobile-Friendly Design

## Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript

## Purpose of the Project

This project was created as part of my web development learning journey and serves as the frontend presentation layer for an HR Management System platform.
